# كودورا أكاديمي | Codora Academy
### منصة تسجيل الطلاب وبوابة الإدارة المشفرة
**إشراف وتدريس:** م. محمد عمارة & م. عمر خالد

---

## 🌟 مميزات المنصة
- **تصميم إنساني نظيف وراقي (Editorial Minimalist):**
  - اعتماد خط **IBM Plex Sans Arabic** المتناسق.
  - ألوان Flat نقية بدون Gradients أو Glow.
  - خالية تمامًا من أي حشو أو كلام ملوش لازمة.
  - إبراز ميزة **"أول سيشن مجانية بالكامل"** في كل مكان لطمأنة الطلاب وأولياء الأمور.
  - تحسين كامل لشاشات الموبايل (حجم ملموم ومريح يمنع السكرول الطويل).

---

## 🔒 حماية وأمان المنصة
- **حجب المسارات الافتراضية:** تحويل مسارات الإدارة التقليدية تلقائيًا لمنع الفحص والتخمين.
- **تشفير كلمات المرور والتحقق التام:** الاعتماد على معايير التشفير (SHA-256) لمنع تسريب بيانات الاعتماد.
- **حماية من هجمات التخمين (Brute-Force Protection):** قفل أمني مؤقت عند تكرار المحاولات الخاطئة.
- **حماية البيانات وحقن الكود (Sanitization & XSS):** تنقية مدخلات التسجيل بالكامل.
- **أمان الاستضافة:** تفعيل ترويسات الأمان الصارمة (HTTP Security Headers) ومنع الفهارس من أرشفة بوابات التحكم.

---

## 🚀 تشغيل المشروع
- تثبيت الحزم: `npm install`
- التشغيل المحلي: `npm run dev`
- البناء للإنتاج: `npm run build`
